## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

The program copies `entry.png` to `/output/entry.png`. The image was drawn as a local HTML front page and captured with headless Chromium; the program itself needs no network and writes the same bytes on every run.
